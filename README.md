# Зурафа — Шахматы Тамерлана

Онлайн-игра в великие шахматы Тимура (шатрандж аль-кабир): доска 11×10, две цитадели, 28 фигур у каждой стороны.

## Запуск

```bash
npm install
npm run dev      # разработка
npm test         # тесты движка и ИИ
npm run build    # статическая сборка в dist/ — годится для любого статического хостинга
```

## Что внутри

- `src/engine` — правила: геометрия с цитаделями, все фигуры, 11 видов пешек, трёхступенчатая пешка пешек,
  принц и рукотворный король, обмен короля, пат = поражение, ничья в цитадели. Спорные правила — опции `RuleOptions`.
- `src/ai` — alpha-beta (PVS, TT, quiescence, LMR) в Web Worker, шесть уровней; режим `analyse` для разбора партии.
- `src/ui/analysis.ts` — оценка ходов (зевок / ошибка / неточность), точность сторон, график оценки.
- `src/ui` — SVG-доска (тап и перетаскивание, клавиатура), игровой экран, обучение фигурам, комплект фигур.
- `src/puzzles.ts` — курс из 13 задач в один ход (фигуры и особые правила); тест проверяет, что у каждой ровно задуманное решение.
- `src/net` — игра по ссылке без регистрации (WebRTC через Trystero/Nostr, серверов нет), часы передаются вместе с ходами.
- `src/i18n` — шесть языков (русский, английский, узбекский, турецкий, китайский, хинди), страницы «Правила» и «История».
- `docs/RESEARCH.md` — выжимка исследования: источники, конкуренты, решения.
- `public/img/` — сжатые кадры из утверждённого набора Flow (обложка, портреты фигур, аватары уровней, иллюстрации, медальоны, иконки). Оригиналы — в `ДИЗАЙН И ФОТО ДЛЯ ИГРЫ/approved/`.
- `design/brand/` — знак «Зурафа», иконки, splash, `tokens.css` и SVG фигур из Claude Design (система пешек «тело + щиток» реализована в `src/ui/pieces.ts`).
- `design/` — аудит визуала (`AUDIT.md`), ТЗ для Claude Design и Google Flow, эталонные рендеры доски и фигур (`refs/`).

Отладка онлайна в одном браузере: вторая вкладка с `?p=2` перед `#` получает отдельную личность игрока.

## Источники правил

Г. Мюррей «A History of Chess» (1913), Д. Форбс (1860), Э. Фалкенер (1892), Г. Бодлендер (chessvariants.com),
Ж.-Л. Казо (history.chess.free.fr). Там, где источники молчат, правило додумано и помечено в коде и на странице «Правила».
