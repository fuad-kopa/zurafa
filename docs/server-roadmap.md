# Зурафа: сервер и дорожная карта

Дата: 2026-09-27. Текущее состояние: статический сайт (Vite) на GitHub Pages, онлайн по ссылке через
Trystero (P2P, публичные nostr-ретрансляторы), профиль и рейтинг только в localStorage браузера.

## 1. Чего не хватает по сравнению с лучшими шахматными приложениями

Сравнивались Chess.com, Lichess, Chessable, Play Magnus, ChessKid, Aimchess, Pychess (сервер вариантов).

| Что есть у лидеров | У нас | Приоритет |
|---|---|---|
| Аккаунты, рейтинг на сервере, подбор соперника, переподключение, зрители | только ссылка P2P, рейтинг локальный | 1 |
| Партии по переписке (ход раз в день), уведомления «ваш ход» | нет | 2 |
| Экспорт/импорт партий (PGN), ссылка на партию, картинка позиции для соцсетей, редактор позиции | нет | 2 |
| Турниры (арена), таблица лидеров, друзья, клубы | нет | 3 |
| Задачи по темам, режим «на время» (rush/storm), повторение с интервалами | 18 задач, задача дня | 2 |
| Уроки с ветвлением и видео, курсы | статичные страницы + задачи | 3 |
| Дебютная база из сыгранных партий, серверный анализ глубже | движок в браузере | 3 |
| Боты с характером (агрессивный, позиционный), «играй как X» | 6 уровней силы | 3 |
| PWA офлайн (service worker), нативные обёртки для магазинов | только manifest | 2 |
| Достижения, серии, еженедельные события | серия задачи дня | 3 |
| Античит, жалобы, модерация | нет (нет смысла без сервера) | после п.1 |
| Режим «вслепую», премувы, подтверждение хода, зен-режим | клавиатура, подсказки | 3 |
| Аналитика и отчёты об ошибках | нет | 2 |

Наше преимущество, которого нет ни у кого: единственное живое приложение именно по шахматам Тамерлана:
битвы на картах, история, резной комплект, шесть языков. Сервер превращает это из «демо» в сообщество.

## 2. Сервер: что уже есть (проверено 2026-09-30, только чтение)

| Что | Значение |
|---|---|
| Провайдер | Contabo, `root@13.140.155.127`, сеть Contabo GmbH (Германия), геолокация IP — Франция. Точный регион виден в панели Contabo |
| Система | Debian 13, 6 CPU, 11 ГБ памяти (занято 1,1), диск 197 ГБ (занято 4 %), нагрузка 0,4 |
| Вход | только SSH-ключ этого ноутбука, ufw (22/80/443), fail2ban |
| Соседи | gorselstar.com: docker compose `gorselstar` (app на 127.0.0.1:3000, postgres, minio), nginx `gorselstar.conf`, certbot, бэкап в 03:30 |

Места хватает с огромным запасом: Зурафе нужно 200–400 МБ памяти.

## 3. Как поставить Зурафу рядом, не мешая gorselstar

```
zurafa.app        → nginx (общий) → статика /var/www/zurafa
zurafa.app/ws     → nginx → 127.0.0.1:3100 (контейнер zurafa-server)
zurafa.app/api    → nginx → 127.0.0.1:3100
PostgreSQL        → свой контейнер zurafa-postgres, свой том, не общий с gorselstar
```

Правила изоляции:
- Отдельная папка `/root/prod/zurafa`, отдельный compose-проект `zurafa`, свой `.env`, свой порт 3100 только на 127.0.0.1.
- Своя база в своём контейнере: обновление, бэкап или сбой одной базы не трогает другую.
- Лимиты памяти и CPU у контейнеров Зурафы (1 ГБ, 2 CPU), чтобы ошибка в игре не задушила gorselstar.
- Отдельный файл `/etc/nginx/sites-available/zurafa.conf`. Файл gorselstar не редактируется. Перед каждым `reload` обязательно `nginx -t`: синтаксическая ошибка в любом файле блокирует перезагрузку для всех сайтов.
- Отдельный сертификат certbot для `zurafa.app` через тот же webroot.
- Свой скрипт бэкапа в 04:00 (у gorselstar 03:30), своя папка `/root/backups/zurafa`.
- Выкладка как у gorselstar: код правится только на ноутбуке, на сервер приезжает через git; статика — `rsync` в `/var/www/zurafa`.

## 4. Пошагово

### Шаг 0. От владельца
- Купить `zurafa.app` (удобно в Cloudflare Registrar, там же DNS gorselstar). DNS: `A zurafa.app → 13.140.155.127`, серое облако, как у gorselstar.
- По желанию `timurchess.ru` и `zurafa.ru` у российского регистратора (Cloudflare .ru не продаёт), редирект на zurafa.app.
- Почта: отдельный аккаунт Resend для Зурафы (на бесплатном плане один домен на аккаунт, домен gorselstar уже занят), добавить домен zurafa.app и DNS-записи SPF, DKIM, DMARC.
- Telegram: бот через @BotFather, команда `/setdomain` → `zurafa.app`.
- Google: OAuth-клиент в Google Cloud Console (тип Web, redirect `https://zurafa.app/api/auth/google`).
- Apple: нужен платный Apple Developer ($99 в год). Можно отложить до выхода в App Store.
- Секреты (ключи Resend, Telegram, Google) владелец вписывает сам в `/root/prod/zurafa/.env` на сервере, в чат их не присылать.

### Шаг 1. Настройка (делаю я после «да» владельца, ~1 час)
Папка, compose-проект, nginx-файл, сертификат, rsync статики. gorselstar не останавливается ни на секунду: nginx перезагружается без обрыва соединений.

### Шаг 2. Игровой сервер (2–3 дня)
Node 22 + `ws` + `pg` в контейнере. Комнаты, поиск партии, часы на сервере, переподключение, зрители, реванш. Ходы проверяет наш же движок. P2P по ссылке остаётся запасным.

### Шаг 3. Аккаунты и рейтинг (2–3 дня)
Гость по умолчанию; вход кодом из письма, через Telegram, Google, позже Apple. Перенос локального профиля. Glicko-2, таблица лидеров, удаление аккаунта в приложении.

### Шаг 4. Переписка, уведомления, Telegram Mini App
Ход раз в сутки, web-push, письма; игра прямо внутри Telegram через Mini App.

### Шаг 5. Эксплуатация
Бэкапы вынести с сервера (сейчас копии gorselstar лежат на том же диске). Мониторинг `/api/health`. `unattended-upgrades`.

### Правовые заметки (не юридическая консультация)
Сервер в ЕС: действует GDPR (согласие, выгрузка и удаление данных). Для граждан России 152-ФЗ требует первичной записи персональных данных в базу на территории РФ; в Узбекистане похожее требование. Храним минимум (почта или идентификатор Telegram/Google и ник). Перед рекламой на Россию и Узбекистан — консультация юриста и, возможно, небольшой узел в РФ.
