# Запуск Зурафы: план, площадки, правила

Готовые тексты постов — в [posts.md](posts.md). Снимки экрана — в [press/](press/) (английский интерфейс, кроме `08-*-ru`).

## Этапы

| Этап | Когда | Цель | Где |
|---|---|---|---|
| 0. Подготовка | до 1 ноября | чтобы тестерам было куда писать и чтобы мы видели статистику | список «Нужно от владельца» ниже |
| 1. Тихая бета | ~3–10 ноября | 20–50 живых игроков, найти ошибки | друзья, Telegram-чаты Узбекистана и Самарканда, шахматные клубы, r/chessvariants, BoardGameGeek |
| 2. Разбор | ~10–14 ноября | исправить найденное, посмотреть, где люди бросают игру | GoatCounter, таблица отзывов в Supabase |
| 3. Широкий запуск | после переезда онлайн-части на сервер, ~середина ноября | сотни и тысячи игроков | Show HN, Product Hunt, r/boardgames, r/chess, клубы вариантов на Lichess и Chess.com, itch.io, YouTube, СМИ UZ/TR/KZ |
| 4. Магазины | после запуска | установка как приложения | Google Play (TWA, $25), RuStore, Telegram Mini App |

Почему широкий запуск только после сервера: сейчас игра по ссылке соединяет браузеры напрямую. На тихой бете это нормально, но при наплыве часть пар не соединится, а рейтинг и часы можно подделать.

## Нужно от владельца перед тихой бетой

1. **Статистика.** Код GoatCounter, под которым вы регистрировались (адрес `zurafa.goatcounter.com` не существует).
2. **Отзывы.** Выполнить SQL из `supabase/migrations/20261028120000_feedback.sql` в Supabase → SQL Editor. Читать отзывы: Supabase → Table Editor → `feedback`.
3. **Почта для входа.** Свой SMTP (Resend) и лимит писем — иначе 2 письма в час.
4. **Telegram-канал** «Зурафа» для новостей и чат для тестеров; ссылку — мне, поставлю на сайт.
5. **Ссылки для поддержки** (Boosty / Ko-fi / Tribute / адрес USDT TRC-20).

## Правила площадок (важно, чтобы не забанили)

- **Reddit.** Самопиар — не больше ~10 % ваших постов и комментариев; аккаунт должен быть живым. Писать от первого лица («я сделал»), спрашивать мнение, отвечать на все комментарии. В r/chess — только по выходным в тредах для своих проектов или если пост интересен сам по себе (история, а не реклама).
- **Hacker News (Show HN).** Вторник–четверг, 14:00–16:00 по Москве (утро в США). Заголовок без восклицаний и эмодзи; первым комментарием — история проекта и технические детали. Не просить голосов.
- **Product Hunt.** Публикация в 00:01 по тихоокеанскому времени (10:01 по Москве), лучше вторник–четверг. Нужны: логотип 240×240, галерея 1270×760 (можно обрезать снимки из `press/`), короткое описание до 260 знаков, первый комментарий автора.
- **BoardGameGeek.** У игры «Tamerlane Chess» есть страница: добавить ссылку в «Weblinks → Online play» и пост в её форуме.
- **itch.io.** Страница игры с внешней ссылкой на zurafa.app (жанр Strategy / Board game), бесплатно.
- **Википедия.** Ссылки на свой проект туда не ставить — удалят и могут заблокировать.

## Что смотреть после каждого поста

- GoatCounter: посетители, откуда пришли, сколько начали партию (`game-start/*`), ошибки (`error/*`).
- Supabase → `feedback`: новые отзывы. Отвечать в течение суток — для тестеров это главное.
- Если пост «выстрелил»: проверить GoatCounter `login/rate-limited` (лимит писем) и нагрузку на GitHub Pages (100 ГБ в месяц).
