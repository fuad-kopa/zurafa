## Незакрытые ниши (наше ядро)

1. Русский язык и СНГ.
2. Игра с другом по ссылке без регистрации.
3. Мобильная версия (390px) + PWA.
4. Обучение на доске: карточка хода любой фигуры, пути прыжков, объяснение особых правил в момент, когда они срабатывают.
5. Читаемые фигуры; 11 видов пешек различимы по силуэту, а не по микрозначку; пешка пешек показывает свою стадию.
6. Переключаемые трактовки спорных правил со ссылками на источники.
7. Тимуридская эстетика: бирюза, ляпис, золото, гирих; цитадели как арочные ниши.

## Технические решения

- **Движок правил**: свой, TypeScript, mailbox на 112 клеток (110 + 2 цитадели), предрасчитанные таблицы ходов, make/unmake. Fairy-Stockfish не подходит (цитадели, жираф, пешка пешек, наследование королей невыразимы).
- **ИИ**: alpha-beta (PVS) + итеративное углубление + TT на typed arrays + quiescence + LMR; осторожный null-move; Web Worker; уровни через (глубина, бюджет узлов, шум оценки).
- **Доска**: самописный SVG, Pointer Events, tap-tap и drag, клавиатурная навигация, aria-live.
- **Онлайн**: интерфейс `GameTransport`; по умолчанию P2P через Trystero (без аккаунтов, статический хостинг); возможен апгрейд на авторитетный сервер Cloudflare Durable Objects (PartyServer).
- **Звук**: синтез WebAudio.
- **Хостинг**: любой статический (Cloudflare Pages / GitHub Pages).
